# 03 周易笺注

> **模块定位**：全书核心母本库，通行本 64 卦权威最终主文档（一卦一档，共 64 卷）。

---

## 📌 母本文档结构与格式红线

每卦主文档必须严格遵循《周易笺注审议与完善系统·标准 v3.3》标准结构，格式统一如下：

1. **卦头元数据**：卦名、卦象符号、六爻阴阳排列、上下卦体配置与核心主要矛盾提炼；
2. **卦辞与彖传**：
   - 经文底本：严格以维基文库通行本底本（`01 审议体系/04_核心数据库/zhouyi.json`）为准；
   - 彖传笺注：唯物辩证解构全卦宏观势态与矛盾转化枢纽；
3. **大象传**：阐明卦象所指示的主体修齐治平与组织行为法则；
4. **六爻逐爻爻解**（初爻至上爻）：
   - 爻辞原典与小象；
   - **时位研判矩阵**：六位阶段特性、阴阳爻性刚柔法则；
   - **唯物辩证笺注**：阶段主要矛盾、主要危险、得吉/致凶机制；
   - **典论核验**：先秦两汉权威原典印证（必须通过 `tools/verify.py` 核验）；
   - **信史史鉴**：先秦至明末崇祯殉国（严格截至 1644 年 4 月 25 日）信史案例对勘；
5. **用九/用六**（乾坤二卦特有）：群龙无首之哲学内涵与生生传承闭环。
