## 一、 版本提要与文献学定位

* **题署与真伪考辨**：《黄金策》含总纲〈千金赋〉及分门详断（天时、年时、国朝、征战、婚姻、产育、求财、疾病等二十余门），旧题**明·刘基（字伯温，诚意伯）**撰。依《四库全书总目》及近代学术史考证，刘伯温乃元末明初开国名臣，精天文兵法而并未见其专著金钱六爻歌诀之正史记载，故“刘基撰”实属明中叶书坊**托名伪题**（与《烧饼歌》《推背图》托名类似，盖明初民间最崇敬伯温先生之神机妙算）。然托名归托名，该赋本身文辞典雅铿锵、理法高度凝练，极可能成于明初至嘉靖年间某位精通《火珠林》的士大夫之手。
* **核心文献锚点**：清康熙年间**《古今图书集成·博物汇编·艺术典·卜筮部》（卷 477 附近及艺文、法则汇考）**收录《黄金策》原文；清初两大六爻巅峰名著——**野鹤老人《增删卜易》**（全书逐句批注评骘〈千金赋〉）与**王洪绪《卜筮正宗》**（开卷即列〈千金赋〉为总纲）皆奉此赋为六爻第一宪章。

## 二、 《黄金策》总断〈千金赋〉100% 完整原文

> **凡例**：以下据《古今图书集成·卜筮部》及清代《卜筮正宗》《增删卜易》通行校本，完整无删节收录〈总断千金赋〉全文，并分段标号便于对照批注。

**【一、总纲与气象损益】**  
动静阴阳，反复迁变。虽万象之纷纭，须一理以融贯。  
人有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。生扶拱合，时雨滋苗；克害刑冲，秋霜杀草。长生帝旺，争如金谷之园；死墓空绝，乃是泥犁之地。

**【二、日辰、月建与岁君身位】**  
日辰为六爻之主宰，喜灭项以安刘；月建乃万卦之提纲，岂助桀而为虐。最恶者岁君，宜静而不宜动；最要者身位，喜扶而不喜伤。

**【三、世应与动变主客】**  
世为己，应为人，大宜契合；动为始，变为终，最怕交争[^note1]。应位遭伤，不利他人之事；世爻受制，岂宜自己之谋。世应俱空，人无准实；内外竞发，事必翻腾。世或交重，两目顾瞻于马首；应好发动，一心似托于猿攀。

**【四、用神旺衰与空合冲破】**  
用神有气无他故，所作皆成；主象徒存更被伤，凡谋不遂。有伤须救，无故勿空。空逢冲而有用，合遭破以无功。自空化空，必成凶咎；刑合克合，终见乖戾。动值合而绊住，静得冲而暗兴。入墓难克，带旺非空。有助有扶，衰弱休囚亦吉；贪生贪合，刑冲克害皆忘。别衰旺以明克合，辨动静以定刑冲。并不并，冲不冲，因多字眼；刑非刑，合非合，为少支神。

**【五、月令、飞伏与日爻互制】**  
爻遇令星，物难我害；伏居空地，事与心违。伏无提拔终徒尔，飞不推开亦枉然。空下伏神，易于引拔；制中弱主，难以维持。日伤爻，真罹其祸；爻伤日，徒受其名。墓中人，不冲不发；身上鬼，不去不安。

**【六、吉凶神煞、长生十二态与动变】**  
德入卦而无谋不遂，忌临身而多阻无成。卦遇凶星，避之则吉；爻逢忌煞，敌之无伤。主象休囚，怕见刑冲克害；用爻变动，忌遭死墓空绝。用化用，有用无用；空化空，虽空不空。养主狐疑，墓多暧昧。化病兮损伤，化胎兮勾连。凶化长生，炽而未散；吉连沐浴，败而不成。戒回头之克我，勿反德以扶人。恶曜孤寒，怕日辰之并起；用爻重叠，喜墓库以收藏。事阻隔兮间发[^note2]，心退悔兮世空。卦爻发动，须看交重；动变比和，当明进退。煞生身，莫将吉断；用克世，勿作凶看。盖生中有刑害之两防，而合处有克伤之一虑。刑害不宜临用，死绝岂可持身。动逢冲而事散，绝逢生而事成。如逢合住，须冲破以成功；若遇休囚，必生旺而成事。速则动而克世，缓则静而生身。

**【七、六亲与六神统论】**  
父亡而事无头绪，福隐而事不称情。鬼虽灾祸，伏犹无气；子虽福德，多反无功。究父母推为体统，论官鬼断作祸殃。财乃禄神，子为福德。兄弟交重，必至谋为多阻滞；卦身重叠，须知事体两交关。虎兴而遇吉神，不害其为吉；龙动而逢凶曜，难掩其为凶。武主盗贼之事，亦必官爻；雀本口舌之神，然须兄弟。疾病大宜天喜，若临凶煞必生悲；出行最怕往亡，如系吉神终获利。

**【八、篇末总归生克之理】**  
是故吉凶神煞之多端，何如生克制化之一理！  
呜呼！卜易者知前则易，求占者鉴后则灵。筮必诚心，何妨子日。

[^note1]: 《卜筮正宗》《增删卜易》本多作“最怕交争”；部分坊刻误作“身相交争”，今依善本校正。
[^note2]: 清刊善本作“事阻隔兮间发”（即世应之间间爻发动阻隔），部分坊刻误作“事阴隔”，今正之。

## 三、 野鹤老人《增删卜易》实证批注对照精要

清代实战大师**野鹤老人**在《增删卜易》中耗费数十年精力、积累大量占验笔记，对《千金赋》作出了震古烁今的**逐句实证勘误（破除伪法、保留真率）**。以下精选最核心的八处“野鹤批注对照”：

| 《千金赋》原文句 | 传统旧注原意 | 野鹤老人《增删卜易》实证驳正与精炼 |
| :--- | :--- | :--- |
| **“最要者身位，喜扶而不喜伤”** / **“卦身重叠”** | 指“卦身”与“世身”（阳世从子起、阴世从午起），古人视为一卦之身命主宰 | **野鹤直斥删除**：数十年实占统计证实，卦身、世身全无应验之力，真正的主体只有**世爻**！“世爻为己，卦身实属赘疣”。 |
| **“用化用，有用无用；空化空，虽空不空”** | 古注极绕，谓用神动化出同五行之用神等 | **野鹤驳正**：用神若化退神、化墓绝、化回头克，岂能“有用”？**“自空化空，若休囚死绝则是真到底空；若旺相有气，则出空可用，全凭旺衰而非空空相抵”**。 |
| **“化病兮损伤，化胎兮勾连……吉连沐浴，败而不成”** | 机械套用长生十二神（病、胎、沐浴）字面吉凶 | **野鹤实证破除**：除**长生、帝旺、墓库、绝**四位经实占确有明显效验外，其余**沐浴、冠带、衰、病、胎、养**多属文人穿凿附会，不可因“吉神化沐浴”便断败！ |
| **“煞生身，莫将吉断；用克世，勿作凶看”** | 煞虽生身仍有刑害；用神克世反主事易到手 | **野鹤极赞此句**：此乃千古妙理！求财求官时，用神（妻财、官鬼）克世爻，只要世爻旺相担得起，反叫**“财来就我、官来就我”**，主得手极快！ |
| **“用爻重叠，喜墓库以收藏”** | 卦中出现多个用神（如两三个财爻）需入墓收敛 | **野鹤修正**：用神多固可参看谁有气谁发动，但**绝非必然喜入墓**；求财用神入墓库反主财物被锁、资金周转不灵，须冲开墓库方可得用。 |
| **“疾病大宜天喜，出行最怕往亡”** | 拘泥于“天喜、往亡、驿马、劫煞”等数十种杂煞 | **野鹤删繁**：卷中《删定神煞》专章证明，天喜、往亡、天医、丧门等杂煞全无实证统计显著性；**只用六神（青龙至玄武）作类象辅佐，余煞一概删去**。 |
| **“虎兴而遇吉神，不害其为吉；龙动而逢凶曜，难掩其为凶”** | 白虎若生用神不凶，青龙若克用神反凶 | **野鹤高度肯定**：彻底打破了“见青龙必喜、见白虎必丧”的呆板标签，把判断权完全归还给**五行生克制化**。 |
| **“吉凶神煞之多端，何如生克制化之一理”** | 结语归宗 | **全书最高纲领**：野鹤称此语“一言破尽千古之惑”，奠定了清代六爻学“去神煞、存生克”的极简理性传统。 |

## 四、 唯物方法论评析：从《千金赋》看中国古代数术的内部自我净化

1. **“一理融贯”的辩证系统观**：
   〈千金赋〉开篇即言“太过者损之斯成，不及者益之则利”，末尾归结为“吉凶神煞之多端，何如生克制化之一理”。这种不满足于碎片化神煞口诀、执意追求底层**统一动力学法则（旺衰平衡 × 生克制化）**的努力，体现了中国古代学者在符号系统内部追求逻辑一致性与奥卡姆剃刀原则（简约性）的高度理智。
2. **野鹤《增删卜易》实证精神的科学史价值（及其限度）**：
   清初野鹤老人用“实占验案对照法”大胆删削了〈千金赋〉中缺乏统计依据的卦身、世身与杂星煞，这在方法论上非常接近朴素的**经验归纳与证伪主义**（在数术史内部剔除了大量无用噪声）。
   * 然而，我们也必须以本工程 `《384爻断辞回测报告》` 的现代统计标准指出其历史局限：古人的“实证核验”缺乏**双盲对照、随机基线检验与样本全量无偏记录**，因此可以淘汰内部最荒诞的神煞噪音，却无法突破“铜钱随机投掷本身不携带外部未来物理因果信息”这一根本数学边界。
3. **最终学术定位**：
   作为传统数术文献，《黄金策·千金赋》不仅文学造诣极高（骈四俪六、对仗工稳），其提炼出的**“动静权重、局部反馈（回头生克）、矛盾转化（贪生忘克、合处防伤、绝处逢生）”**思维模型，迄今仍具有极佳的战略风险推演启发价值——只要将其置于“易理与术数划界”的唯物坐标系下理性审视，便能取其系统分析之长，而绝不堕入迷信之阱。
