## 一、 版本源流提要与文献考辨

### 1.1 官修背景与《四库》辑录历程
《景祐遁甲符应经》三卷，北宋景祐年间（1034—1038 年）司天监**杨惟德、何湛、王立**等奉宋仁宗诏撰，与《景祐太乙福应经》《景祐六壬神定经》并称“景祐三式”（见《宋史·艺文志》）。明代以后单刻本罕见，清初**《古今图书集成·博物汇编·艺术典·术数部》（卷 621–630）**大量采录其起例、九星八门与十干克应条文；乾隆年间四库馆臣又据**《永乐大典》“遁”字、“甲”字韵**及内府秘阁残本重新辑校成三卷，收入《四库全书·子部·术数类》。

### 1.2 学术史地位：为何它是术奇门“十干克应”的源头祖本？
《四库全书总目·景祐遁甲符应经提要》明确指出：“其书专论兵家遁甲之术，视后来伪托《秘笈大全》诸书，犹为古法之正。”相传唐宋以前遁甲书籍多已散佚，《景祐遁甲符应经》是**现存最早、最权威的官修奇门遁甲标准教科书**。今天奇门界通行的一切核心规则——包括**二十四节气超神接气置闰法、六仪三奇命名、九星八门八神原义，以及完整 10×10 矩阵的“十干加临克应断辞”**——其文字定型均源于此书。

## 二、 核心卷次原文精录、校勘与注释

### 2.1 卷上·《遁甲总序》与《三奇六仪解》

> **【原文精录】**
> 遁甲之法，盖本于黄帝、风后，推之以八卦，布之以九宫，行之以六甲，配之以三奇、六仪、八门、九星，而主客胜负、动静行藏莫不备焉。
> 何谓**遁甲**？甲为十干之首，尊而不临，常隐于六仪之下，故曰“遁甲”。
> 何谓**六仪**？甲子遁于戊，甲戌遁于己，甲申遁于庚，甲午遁于辛，甲辰遁于壬，甲寅遁于癸，是谓六仪（六甲仪仗旗帜也）。
> 何谓**三奇**？乙为日奇，丙为月奇，丁为星奇。甲畏庚金克害，故乙以妹妹合庚（乙庚合），丙以子息制庚（丙火克庚），丁以阴火炼庚（丁火锻金），三者皆助甲胜庚，故曰“三奇”。
> 推阴阳二遁法：冬至一阳生，起于坎一宫，顺行九宫；夏至一阴生，起于离九宫，逆行九宫。一节统三元（上、中、下各五日），五日一换局。若符头先于节气，谓之超神；节气先于符头，谓之接气。超神过九日，则置闰于芒种、大雪之后，以合天时。

- **【注释与考辨】**
  1. **军事隐喻定型**：本段首次在官修文献中把“遁甲”系统化地阐释为**“元帅隐蔽（甲隐六仪）+ 亲族外交与武力制敌（乙合庚、丙丁克庚）”**的兵家模型，彻底脱离了东晋《抱朴子》纯粹念咒隐身的宗教思路。
  2. **置闰法则的官方确立**：明确写出“**超神过九日，置闰于芒种、大雪之后**”，证实“置闰法”确为北宋司天监的正统官方历算法则。

### 2.2 卷中·《九星八门九宫吉凶克应原文》

> **【原文精录】**
> - **天蓬星**（水，贪狼，居坎一宫）：太乙之水星也，大凶（一曰智谋险阻）。宜安抚边境、修筑城池、阴谋秘计，忌兴兵远出、嫁娶移徙。
> - **天芮星**（土，巨门，居坤二宫）：阴土凶星也。宜受道结友、屯兵固守、察奸问疾，忌用兵交战、诉讼争讼。
> - **天冲星**（木，禄存，居震三宫）：慈心造化之吉星也（又主迅捷冲锋）。宜鸣鼓出师、报仇雪耻、振奋士气，忌嫁娶交易、阴谋潜伏。
> - **天辅星**（木，文曲，居巽四宫）：文昌大吉星也。宜修文设教、上书言事、拜将封侯、百事皆吉。
> - **天禽星**（土，廉贞，居中五宫）：中正大吉之星也。百事咸宜，尤为统帅中军立营之象（寄随坤二而行）。
> - **天心星**（金，武曲，居乾六宫）：天医大吉星也。宜治病求药、参谋画策、惩罚奸佞、赏功罚罪。
> - **天柱星**（金，破军，居兑七宫）：金星小凶也。宜屯兵坚守、修筑营垒、藏形匿迹，忌远行商贾、嫁娶兴工。
> - **天任星**（土，左辅，居艮八宫）：阳土吉星也。宜请谒见贵、垦荒屯田、嫁娶百事，稳重无虞。
> - **天英星**（火，右弼，居离九宫）：烈火中平（小凶）星也。宜献策陈言、宴会明堂、用火攻敌，忌涉水求财、阴私隐匿。
> 
> 论**八门吉凶**：
> - **休门**（居坎）：宜休兵养士、上官见贵、和合婚姻、安营定计。
> - **生门**（居艮）：大吉之门，宜出师讨贼、求财营建、屯垦积粮。
> - **伤门**（居震）：宜捕捉盗贼、猎兽索债、正面攻坚；不利行船嫁娶。
> - **杜门**（居巽）：宜藏形躲避、断绝道路、构筑工事、保守机密。
> - **景门**（居离）：宜发布文书、举火焚营、破阵扬威、上书奏对。
> - **死门**（居坤）：大凶之门，惟宜吊丧葬埋、决狱行刑、筑墓立碑。
> - **惊门**（居兑）：宜设疑惊敌、词讼争辩、捕盗鸣锣；忌远行安营。
> - **开门**（居乾）：大吉之门，宜开通道路、大将出征、见贵立业、远行求利。

### 2.3 卷下·《十干加临克应断辞全文》（天盘十干加地盘十干核心矩阵）

《景祐遁甲符应经》最具工程价值的部分，是完整构建了**天盘奇仪（乙丙丁戊己庚辛壬癸，含六甲隐干）加临地盘奇仪**的克应辞典（以下依《四库》本与《古今图书集成》卷 625–627 精录其核心正条）：

#### （一） 三奇加临地盘十干（乙、丙、丁）
1. **天盘乙奇（日奇）加临地盘**：
   - `乙 + 戊`（阴害阳门）：利于阴谋、私事，不利阳刚公开之举；若得吉门可成；
   - `乙 + 己`（日奇入雾）：被土暗昧遮蔽，主文书不明、前途昏暗，宜退守；
   - `乙 + 庚`（日奇被刑）：乙庚虽合，但庚金克木带刑，主夫妻反目、将帅内讧、合作争讼；
   - `乙 + 辛`（**青龙逃走**）：阴金直克阴木，主奴仆逃亡、部属叛离、百事破财损兵；
   - `乙 + 壬`（日奇入地）：主尊卑紊乱、官讼牵连、谋事多变；
   - `乙 + 癸`（日奇入天网 / 华盖逢星）：宜隐遁藏迹，不宜显露争先；
   - `乙 + 乙`（日奇伏吟）：宜安静守成，不可妄动；
   - `乙 + 丙`（奇仪顺遂）：吉星利升迁、加官，凶星防夫妻离别；
   - `乙 + 丁`（奇仪相佐）：文书大吉，最利考试、谋划、婚姻。

2. **天盘丙奇（月奇）加临地盘**：
   - `丙 + 戊`（**飞鸟跌穴**）：大吉格，主谋事顺遂、不费力而成功、营盘稳固；
   - `丙 + 己`（火悖入刑 / 太悖）：主囚狱官非、文书出错、口舌是非（得吉门稍解）；
   - `丙 + 庚`（**荧入太白**）：火克金，主贼兵退去、破敌防线，若求财谋事则多阻折；
   - `丙 + 辛`（**日月相会 / 谋事成就**）：丙辛合化水，主和合顺利、病人遇良医；
   - `丙 + 壬`（火入天罗）：主为客不利、是非缠身、多有惊恐；
   - `丙 + 癸`（华盖悖师）：阴人害事，灾祸频生，防伏兵暗算；
   - `丙 + 乙`（日月并行）：公私皆吉，和顺通达；
   - `丙 + 丙`（月奇悖师）：文书逼迫、破耗遗失、暴躁失控；
   - `丙 + 丁`（星奇朱雀）：文书大吉、贵人扶助、声名显赫。

3. **天盘丁奇（星奇）加临地盘**：
   - `丁 + 戊`（**青龙转光**）：火土相生，主官爵升迁、贵人提携、远行大利；
   - `丁 + 己`（火入勾陈）：主奸私仇怨、因私欲而遭官非；
   - `丁 + 庚`（年月日时格 / 文书阻隔）：行人必归，音信先阻后通；
   - `丁 + 辛`（朱雀入狱）：罪人释囚，官司先困后解，或奴婢背主；
   - `丁 + 壬`（**五神互合 / 奇仪相合**）：丁壬合木，主贵人相助、讼狱和解、文书喜庆；
   - `丁 + 癸`（**朱雀投江**）：文书沉溺、音信断绝、口舌官非、水火相伤；
   - `丁 + 乙`（人遁吉格 / 玉女奇生）：贵人加官、婚姻和合；
   - `丁 + 丙`（星随月转）：贵人越级提升，防自矜骄纵；
   - `丁 + 丁`（奇入太阴）：文书即至，喜事遂心。

#### （二） 六仪加临地盘十干（戊、己、庚、辛、壬、癸）
4. **天盘戊（甲子）加临地盘**：
   - `戊 + 戊`（青龙伏吟）：百事停滞守旧；`戊 + 己`（贵人入狱）：公私皆不利，破财被困；
   - `戊 + 庚`（**值符飞宫**）：主移居、换将、丢官失地；`戊 + 辛`（青龙折足）：吉门可谋，凶门防足疾破财；
   - `戊 + 壬`（青龙入天牢）：内外不利；`戊 + 癸`（**青龙华盖**）：戊癸合，吉门招福、凶门多阻；
   - `戊 + 乙`（青龙合会）：门吉事吉；`戊 + 丙`（**青龙返首**）：大吉大利，百事兴旺（惟忌门迫击刑）；`戊 + 丁`（青龙耀明）：宜谒见贵人、求名升职。
5. **天盘己（甲戌）加临地盘**：
   - `己 + 戊`（犬遇青龙）：门吉谋望遂心；`己 + 己`（地户逢鬼）：病者大凶，事多迟滞；
   - `己 + 庚`（刑格返名）：词讼先动者不利，防阴谋陷害；`己 + 辛`（**游魂入墓**）：易招鬼魅惊吓、小人暗算；
   - `己 + 壬`（地网高张）：狡童佚女、奸情败露、防暗损；`己 + 癸`（地刑玄武）：男女疾病垂危、词讼囚狱；
   - `己 + 乙/丙/丁`（墓神不明 / 火悖地户 / 朱雀入墓）：多主先暗后明或冤狱难伸，需吉门扶助。
6. **天盘庚（甲申）加临地盘**：
   - `庚 + 戊`（**天乙伏宫**）：百事大凶，主破财换防、防突袭；`庚 + 己`（**刑格**）：官司重重、主客两伤；
   - `庚 + 庚`（**太白同宫 / 战格**）：官灾横祸、兄弟反目、两军死斗；`庚 + 辛`（**白虎干格**）：不宜远行，车马折伤、大凶；
   - `庚 + 壬`（**小格 / 上格**）：远行迷失、音信全无；`庚 + 癸`（**大格**）：行人不至、官司难解、产母有厄；
   - `庚 + 乙`（**太白逢星**）：退吉进凶；`庚 + 丙`（**太白入荧**）：占贼必来，防偷营劫寨；`庚 + 丁`（亭亭之格）：私匿起官司，门吉可救。
7. **天盘辛（甲午）加临地盘**：
   - `辛 + 戊`（困龙被伤）：官司破财、屈抑难伸；`辛 + 己`（入狱自刑）：奴仆背主、讼难伸理；
   - `辛 + 庚`（白虎出力）：刀刃相接、主客相残、强进血光；`辛 + 辛`（伏吟天庭）：自误自伤、公废私愁；
   - `辛 + 壬`（凶蛇入狱）：两男争女、讼狱不息；`辛 + 癸`（天牢华盖）：日月失明、误入天网；
   - `辛 + 乙`（**白虎猖狂**）：家破人亡、远行多殃、合作崩盘；`辛 + 丙`（干合悖师）：荧惑出现、因财致讼；`辛 + 丁`（狱神得奇）：经商获倍利、囚人遇赦免。
8. **天盘壬（甲辰）加临地盘**：
   - `壬 + 戊`（小蛇化龙）：男人发达、产育吉祥；`壬 + 己`（反吟蛇刑）：大祸将至、顺守可安；
   - `壬 + 庚`（**太白擒蛇**）：刑狱公平、立剖邪正；`壬 + 辛`（螣蛇相缠）：纵得吉门亦主纠缠不清；
   - `壬 + 壬`（蛇入地罗）：外人缠绕、内事索索；`壬 + 癸`（**幼女奸淫**）：家有丑声、阴私是非（亦主外吉内凶）；
   - `壬 + 乙`（小蛇得势）：柔顺得利；`壬 + 丙`（水蛇入火）：官灾刑禁、络绎不绝；`壬 + 丁`（干合蛇刑）：文书牵连、贵人匆匆（女吉男凶）。
9. **天盘癸（甲寅）加临地盘**：
   - `癸 + 戊`（天乙会合）：财喜婚姻、吉人赞扶；`癸 + 己`（华盖地户）：男女占之音信皆阻、躲灾可避；
   - `癸 + 庚`（**太白入网**）：以暴力争讼、自罹罪网；`癸 + 辛`（网盖天牢）：占病占讼死罪难逃；
   - `癸 + 壬`（复见螣蛇）：嫁娶重婚、后嗣无成；`癸 + 癸`（**天网四张**）：行人失伴、病讼皆伤；
   - `癸 + 乙`（华盖逢星）：贵人禄位、明暗交错；`癸 + 丙`（华盖悖师）：贵贱不利、上下失和；`癸 + 丁`（**螣蛇夭矫**）：文书官司、火焚惊虚。

## 三、 考辨与历史唯物主义总结

1. **天盘（动/客）与地盘（静/主）的相生相克编码律**：
   通检上述 100 组十干克应断辞，绝非无规律的随机胡诌，而是严格遵守两条底层代数规则：
   - **五行生克规则**：凡天盘五行生助或合化地盘（如 `戊+丙` 木火相生、`丁+壬` 相合、`丙+辛` 相合），主系统协同增效（吉格）；凡天盘与地盘金木交战或水火相激（如 `辛+乙` 白虎猖狂、`癸+丁` 螣蛇夭矫、`庚+丙` 白入荧），主系统对抗损耗（凶格）；
   - **符号角色编码**：`庚` 永远代表敌方兵戈阻隔（太白），故所有含 `庚` 组合皆偏重战事、刑格、大格、小格；`丁` 永远代表文书信息，故 `丁+癸` 必断文书沉溺、音信断绝。
2. **北宋边防需求下的规范化手册**：
   《景祐遁甲符应经》将此前隐秘零散的口诀标准化为查表式军事参谋字典，其历史贡献在于保存了宋代官学历算与兵阴阳文献原貌；其时代局限则在于将复杂战局简化为十干克应标签，唯物史观研读者须将其视为**古代离散符号推理模型**，绝不可作迷信宿命占验之用。
