# 03 周易数术源流编（从汉代象数模型到《古今图书集成》数术体系通考）

> **所属主线**：[`08 周易源流与哲学史/`](../README.md)  
> **研究视角**：聚焦“**术·数·用**”——以《周易》阴阳协和为体，以八卦、河图洛书九宫、十二消息、二十四山与五行生克为数理引擎，考察中国古代太乙、奇门（术奇门与法奇门）、大六壬、六爻纳甲、四柱八字、紫微斗数、风水堪舆、相术摸骨等数术体系的历史源流、经典典故、文献载体与核心演算原理。  
> **价值基准**：初始暂定 **2 级（核心依赖因子 0.3）**，具体专论提交用户终审确权。

---

## 🔗 与既有 1 级公理及双编的边界划定

本编严格遵守 [`《十数概论》`](../../02%20元研究/十数概论.md)（1 级待终审）确立的**“易理与术数划界”**原则：
1. **不以术数倒推《周易》本源**：明确区分先秦《周易》古经与《十翼》的辩证哲学本体，与汉代以后逐步耦合天文历法、干支五行、式盘星占而形成的“技术化数术体系”。黑白点“河图洛书”图式属宋代图书学后设建构，不得倒推为殷周古经原貌；但作为唐宋以后各派数术（如理气堪舆、奇门、紫微）的共同数理接口，须在数术史框架内客观还原其组装逻辑。
2. **历史唯物主义去魅原则**：剥离数术文献中的谶纬宿命论、鬼神符箓附会与江湖伪托（如“诸葛亮借东风”“陈抟著紫微斗数”等演义叙事），还原其背后的**古代天文历法离散化（干支纪时、二十四节气、岁差）、空间方位测绘（二十四山、九宫格）、环境生态经验（堪舆选址）与决策博弈心理模型**。
3. **三编互证关系**：
   - [`01_周易源流编/`](../01_周易源流编/README.md)（器·文·本）提供出土简帛与传世版本坐标；
   - [`02_周易哲学史编/`](../02_周易哲学史编/README.md)（道·理·派）提供汉唐宋明清象数哲学背景；
   - 本编（`03_周易数术源流编/`，术·数·用）专司追踪象数哲学向实用数术模型的分支外溢与技术演化。

## 📚 核心文献底座总目（四重证据锚点）

本编研究以**三大传世巨帙**为核心文献载体，并以**正史艺文志**与**出土考古实物**作交叉校准：

| 证据层级 | 核心文献 / 实物载体 | 收录数术核心门类与学术价值 |
| :--- | :--- | :--- |
| **第一重（清代集大成官修类书）** | **《古今图书集成·博物汇编·艺术典》**（清康熙末陈梦雷编、雍正四年蒋廷锡校定，共 824 卷；含**卜筮部、星命部、相术部、术数部、堪舆部**） | 迄今保存清以前数术文献最完整之总汇，按“汇考、总论、艺文、纪事、杂录、外编”六目分部，囊括六壬、奇门、太乙、纳甲、八字、斗数、堪舆、相术之辑佚与原典。 |
| **第一重（明代大类书辑佚源）** | **《永乐大典》**（明永乐年间解缙、姚广孝等编；存目及现存残卷、清代《四库全书》辑本） | 抢救保存大量宋元以前已佚数术古籍（如部分式经、葬书、命理歌赋），为辨析唐宋数术原始面貌与明清改写层累之关键标尺。 |
| **第一重（道教经藏文献群）** | **《道藏》**（明《正统道藏》及《万历续道藏》） | 尤以洞真、洞神、太玄、正一诸部为要，保存“法奇门”（六甲符箓、禹步祈禳）、道教星官与紫微星垣体系、太乙神数道法化文本及《阴符经》数术注疏。 |
| **第一重（正史目录锚点）** | **《汉书·艺文志·数术略》**（天文、历谱、五行、蓍龟、杂占、形法六类）及《隋书·经籍志》《宋史·艺文志》《四库全书总目·子部·术数类》 | 确立中国古代数术门类划分的官方目录学源头，检验后世“三式”“八字”“斗数”之托古伪作。 |
| **第二/四重（出土简帛与实物）** | **阜阳双古堆汉简太乙九宫占盘**、**孔家坡/周家台/睡虎地/放马滩秦汉简《日书》**、**出土六壬式盘（汉至唐）**、**汉唐铜镜与司南/罗盘演变实物** | 直接印证九宫数、六壬式盘、建除十二神、干支纳音在秦汉之际的物质形态，破除“宋人始创”或“上古黄帝亲授”双重偏误。 |
