# 02 周易哲学史编（从先秦生生萌芽到当代实践唯物论）

> **所属主线**：[`08 周易源流与哲学史/`](../README.md)  
> **研究视角**：聚焦“**道·理·派**”——历代易学哲学范式、认识论与本体论转向、象数与义理之争、唯物与唯心两条路线的历史交锋，以及对“生生”与“矛盾辩证法”的继承与扬弃。  
> **价值基准**：初始暂定 **2 级（核心依赖因子 0.3）**，具体专论提交用户终审确权。

## 🧭 总纲方法论：用《矛盾论》与“生生”标尺重绘易学哲学史

历代易学哲学史并非单纯的“学术流派罗列”，而是特定历史生产方式与政治矛盾在哲学意识形态上的折射：
1. **辨别两条路线**：剥离以天人感应、谶纬宿命、先天象数神学为核心的**唯心主义与机械论支流**；发掘并重塑以“变动不居”“刚柔相推”“一阴一阳之谓道”“生生之谓易”“穷则变、变则通、通则久”为核心的**朴素唯物论与辩证法主脉**。
2. **坚持时位分析**：任何易学家的哲学命题，必须放回其所处的社会主要矛盾与阶级/制度处境中去理解（如汉代大一统神学化、魏晋门阀玄学化、宋代危机与理学重建、明清之际实学批判、近代救亡图存下的科学化转型）。
