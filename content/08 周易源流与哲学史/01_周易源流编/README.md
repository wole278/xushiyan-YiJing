# 01 周易源流编（从史前数字卦到当代出土文献重构）

> **所属主线**：[`08 周易源流与哲学史/`](../README.md)  
> **研究视角**：聚焦“**器·文·本**”——符号起源、占筮制度演变、经传成书年代、传世与出土版本流变、历代目录与校勘学史。  
> **价值基准**：初始暂定 **2 级（核心依赖因子 0.3）**，具体专论提交用户终审确权。

---

## 🔗 与 `02 元研究/` 既有 1 级基石的衔接

本编不脱离既有成果另起炉灶，而是在以下 **1 级元研究基石**之上向纵向历史深处展开：
- [`三易归源论.md`](../../02%20元研究/三易归源论.md)：确立《连山》《归藏》《周易》三易演化与历史哲学渊源；
- [`商论.md`](../../02%20元研究/商论.md)：确立殷商甲骨卜辞与商周之变制度史基准；
- [`易经文物注.md`](../../02%20元研究/易经文物注.md)：确立青铜铭文与先秦礼器实物校准标尺；
- [`十数概论.md`](../../02%20元研究/十数概论.md)：确立一至十数理源流及“图式与典籍先后之辨”准则。

## 🗺️ 研究规划纲要（从古到今七大断代专题）

| 序列 | 拟定专题方向 | 核心历史对象与关键实证材料 | 状态 |
| :---: | :--- | :--- | :---: |
| **01** | **史前至商周：数字卦与《周易》符号系统起源** | 陶寺、周原、张家坡、安阳殷墟等数字卦刻符；“奇偶—阴阳”符号抽象的唯物基础；《连山》《归藏》与《周易》的制度衔接 | 🟢 初稿完成（2 级暂定） |
| **02** | **西周至春秋：《周易》古经成书与《左传》《国语》筮例源流** | 西周初期历史记忆（“高宗伐鬼方”“帝乙归妹”“箕子之明夷”等）在经文中的层累；春秋时期“观象玩辞”向伦理政治推演的转型 | 🟢 初稿完成（2 级暂定） |
| **03** | **战国至秦汉：《十翼》成传与出土简帛《周易》版本流变** | 郭店简、上博简、清华简《筮法》、阜阳汉简、马王堆帛书《周易》（含《二三子问》《系辞》《易之义》等）；今古文经学分合 | 🟢 初稿完成（2 级暂定） |
| **04** | **汉唐时期：熹平石经、王弼注本与《周易正义》定本形成** | 施孟梁丘与费氏易消长；郑玄、王弼注本竞争；唐孔颖达《周易正义》合经传为一书的定本化历程与李鼎祚《周易集解》存古之功 | 🟢 初稿完成（2 级暂定） |
| **05** | **宋元明时期：雕版印本流变与图书文献之源流辨伪** | 宋代国子监本、朱熹《周易本义》复吕祖谦古本（经传分离）与明代《永乐大全》合刊之反复；河图洛书先天图文献出现年代的实证辨伪 | 🟢 初稿完成（2 级暂定） |
| **06** | **清代时期：四库整理、辑佚学与汉易古本重现** | 惠栋、张惠言、孙堂、马国翰对汉魏三十余家易注的辑佚工程；清代校勘学对经文字句异文的清理 | 🟢 初稿完成（2 级暂定） |
| **07** | **近现代至当代：新出土简帛与现代数字底本工程重估** | 1973 马王堆帛书、1993 郭店简、1994 上博简、2008 清华简、2015 海昏侯简等对传世本的校勘突破；本库 `zhouyi.json` 四部丛刊影印校准与 `canon.lock.json` 数字化工程 | 🟢 初稿完成（2 级暂定） |
