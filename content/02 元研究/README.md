---

## 📌 模块宗旨与边界

元研究是整部《周易》体系的理论底座与哲学基石。本模块不局限于某卦某爻的局部考据，而是聚焦于易经哲学宏观体系的“元范畴”与“元命题”，包括：
1. **本体论范畴**：太极、阴阳、一、动静、体用；
2. **结构范畴**：三才（天、地、人）、六位、刚柔、中正、乘承应比；
3. **演进规律**：恒道、变易、简易、不易、生生之谓易；
4. **历史唯物考据**：商周礼制、青铜铭文与实物文物对易经哲学起源的实证反哺。
