# 乾坤生息论

## 一、 生命之问：生机自何而来，又从何而逝？

天地之间，最不可思议之大奇迹，莫过于生命之诞生与消逝。

现代医学与物理学者，常将生命视作细胞之分裂、蛋白质与核酸之化学堆叠。然而，若仅有血肉形质，纵使精卵相聚、分子备具，何以在不可思议之刹那，生命之火赫然被点燃？何以人至寿终气绝，全身器质尚在，而那一抹温煦灵动的生机却已荡然无存？

**生机究竟自何而来？又从何而逝？**

《周易·系辞上》开篇明示生死之枢机：
> **“原始反终，故知死生之说。精气为物，游魂为变，是故知鬼神之情状。”**

万物之生，非凭空偶合；万物之死，非形体孤散。深入生命孕育与离散之真际，方知《周易》乾坤之设，绝非书斋中玄虚之符号，而是中华先哲对宇宙生命生灭律则最深刻、最直观的体认。

## 二、 乾炁降落：一点生机点燃生命

人胎生受孕之时，父母精血交感，构筑肉身胚胎之形体。然而，单纯之父精母血不过是物质之“地”（坤土载体）。

在受胎的那一玄妙时刻：
**一点真纯的生机，自浩瀚宇宙虚空中应感降落，如闪电破夜、燧石出火，刹那间点燃了胚胎的生命之火。**

**这一炁生机，便是纯阳之【乾炁】！也为生机**

```
                  【浩瀚宇宙太虚】
                         │

      （生命真正源头·始生之源·周流通达·利生之德）

              ┌─────────────────────┐
              │  【母胎肉身·坤体】  │

              │ （万物生成之所·承载）│
              └─────────────────────┘
                         │
                         ▼
              【乾坤相合 ═══> 生发！】
```

乾炁之于生命，具足“元、亨、利、贞”四维本体：
1. **元（始生之源）**：它是生命真正无可替代的本源起点。没有这一滴自宇宙垂降的乾阳灵性，形质不过是一团死肉，断不可成活。《彖》曰：“大哉乾元，万物资始，乃统天。”
2. **亨（周流之道）**：乾炁在宇宙中本自流通无阻，一旦入胎，便在微茫胚胎与血脉经络中周流不息，推荡气血，演化五脏六腑，化生百骸。《彖》曰：“云行雨施，品物流形。”
3. **利（生长之得）**：乾炁之德唯在生生，它利于生命之开始，普润形体，使细胞得以繁衍、器官得以条达，不求自报而润养全躯。《文言》曰：“乾始能以美利利天下，不言所利，大矣哉！”
4. **贞（正大光明）**：乾炁煌煌正正，主宰生命节律与抗邪防腐之生机中枢，赋予生命自律、修复与生生不息之正道本性。《文言》曰：“刚健中正，纯粹精也。”

## 三、 人体为坤：承载化生之器

如果说乾炁是点燃生命的火种与源源不绝的能量流，**那么人体躯壳便是【坤】**。

《说文》：“坤，地也，从土从申。”《象》曰：“地势坤，君子以厚德载物。”
1. **血肉筋骨为坤土**：母体胎宫、受精卵胞、血脉皮肉，皆是由水谷精微与物质资料化合而成之坤土具象。它是生命寄托之宅舍；
2. **万物生成之所**：坤地厚重柔顺，“万物资生，乃顺承天”。坤土不自居其功，以其博大深厚之容载力，无条件地顺承乾炁之生发指令，日夜孕育滋培，终使十月胎完，形神具备；
3. **不习无不利**：坤地纯任自然造化，不假造作，气血运行，各循其经，故能使胚胎由微细一粟成长为完具百骸的婴儿。

## 四、 生死合离：乾坤聚散之大律

由此彻悟生命诞生与终结之唯物真际：

```
【乾坤合离与生死运行律则】

       【生（Life）】                        【死（Death）】
  乾阳天炁 ────┐                       乾阳清炁 ────> 归于太虚宇宙（游魂为变）
               ├──> 乾坤相合（生发）                  
  坤阴血肉 ────┘                       坤阴浊骸 ────> 归于大地泥土（精气散灭）
（阳入阴中，神形合一，周流通达）     （乾坤相离，形骸腐散，生机告熄）
```

### （一） 乾坤相合，便是生发（生）
- 乾阳之神气与坤阴之血肉水乳交融，两两相抱。“天地氤氲，万物化醇；男女构精，万物化生”（《系辞下》）。
- 乾得坤而有其体，坤得乾而有其神；乾动于内，坤顺于外。此时生命系统开始运转，气血充盈，周流通达，智识开朗，此之谓**生发**（《泰》卦天地交而万物通）。

### （二） 乾坤相离，便是死亡（死）
- 寿数穷极，或遭遇大疾重创，形体衰朽残破（坤体漏损），不能再固摄承载乾炁；或元气耗竭（乾炁衰竭），不足以统摄坤骸。
- 最终那一刹那：**乾炁拔离肉体，上升复归于宇宙太虚；坤阴躯壳失却生机，冰冷僵硬，入土复归于尘沙大地。**
- 乾坤相离，神形解体，能量与物质各归其所，生命系统热力学熵增至极大，此之谓**死亡**（《否》卦天地不交而万物不通）。

庄子所谓“人之生，气之聚也；聚则为生，散则为死……通天下一气耳”（《庄子·知北游》），所言正是乾坤二炁之聚散大化！

### （一） 道家实证：张三丰《大道论》的生命全息解构

一代太极宗师张三丰在《大道论》中，清晰剖析了从无极虚空到乾坤化生的受胎与衰亡全过程：
> “大道，统纳了天、地、人和万物生化的道理，包涵了阴、阳、动、静的法则，具有造化自然的能力……  
> 如果现在从人的生命的角度来谈论从『无名』到『有名』的过程。那么，在父母生育之前，我们都是一片虚无，托付于无极虚空之中，这就是人的生命的『无极』时期……  
> **当父母开始交媾，有一股灵气注入了母胎之中，这标志着『太极』的开始。**『太极』代表了阳性开始发动……当阳性和阴性在母胎中相互作用时，**如果乾道成主，则孕育出男性；如果坤道成主，则孕育出女性。**  
> 因此，当男性和女性交合时，男性的精子和女性的卵子相结合，混合成一个新的生命，这就是人体的基础。之后，父亲的精气储存在胎儿的肾脏中，母亲的精血储存在胎儿的心脏中，胎儿的心肾相互连通，并随着母亲的呼吸而呼吸，经过十月怀胎，胎儿的形体发育完全，从母亲的胎腹中产出……  
> 沉静的气脉中孕育了元神，叫做先天真性；心神寂静中自然生发的元气，就是先天真命。混混沌沌的婴儿，自然拥有的就是天命天性……  
> 然而，随着人成长中思维的日益清晰……我们的内心开始受到七情六欲的波动，千万个思绪纷至沓来，昼夜间思绪都不会有片刻停止。心神的不断运转使得我们的精神逐渐疲惫，精力不断被消耗，而身体也因年岁的增长而变得脆弱，生老病死的困扰开始显现……”

张三丰先生之论，精微至极：
1. **父母交媾时“有一股灵气注入母胎”，即是宇宙真纯之乾炁感应降落！** 这一注入点燃了原本静止的虚空，太极始动；
2. **“乾道成男，坤道成女”**：纯阳乾炁与母腹坤体相互交感互塑，精气藏肾（先天水），精血藏心（先天火），水火既济，十月乃成；
3. **后天衰亡之乾坤相离**：成长之后，七情耗散、万虑煎熬，心神元气日益脱竭，最终精尽气绝，乾阳拔离，坤骸散灭。

### （二） 佛家实证：西晋竺法护译《佛说胞胎经》的受孕与流转全息论

西晋月氏国三藏竺法护所译之《佛说胞胎经》（与《大宝积经·入胎藏会》同本异译），被誉为东方古代人类胚胎发生学的旷世巨著。释迦牟尼佛在经中详细开示了人类受孕之真机：
1. **三缘和合入胎**：受胎绝非单纯之父精母血交会。经云：“何谓父母和合有胎？若父母起染污心，因缘和会，母身清净……当此之时，**中阴神识现前，随其业缘，入母胎中**，与父精母血合和凝集，如醍醐酪，初七日名曰羯罗蓝。”
   - 父母精血不过是物质之“地”（坤土载体）；
   - **随业感应降落入胎的中阴神识，正是点燃胚胎生机的宇宙之光（乾阳之炁）！** 若无神识入胎，精血便化为死物败坏流出；
2. **三十八周风大周流（气行成形）**：
   - 经中详述胎儿在母腹三十八周（二百六十六日）之发育过程，每周皆由宇宙“风大”（元气周流）旋转鼓荡，开导眼耳鼻舌诸窍，生发骨节筋脉、血脉经络。这正是乾道之**“亨（周流之道）”**与坤道之**“利（生长之得）”**在母腹中的精微化育；
3. **命终离散**：临终之际，四大（地水火风）依次分解，呼吸断绝，神识脱壳拔离（乾阳归天，坤土归地），色身彻底丧失温度生机，归于腐朽。
