# 徐时言-易经研究

欢迎阅读。本站收录经过四级审议定稿的《周易》研究成果，共 6 个研究分支、168 篇（更新于 2026-11-21）：

- **02 元研究**（10 篇）：本体论公理与方法论专论
- **03 周易笺注史鉴**（73 篇）：64 卦权威笺注主母本 + 十翼传文底本（65–72）
- **05 词义研究记录**（10 篇）：甲骨金文字源、全经穷尽式词义训诂
- **06 融合研究记录**（7 篇）：历史、考古与经传交叉研究
- **08 周易源流与哲学史**（18 篇）：从古到今的《周易》文本源流考辨与易学哲学思想史研究主线
- **09 周易数术纲目**（50 篇）：共性基座（阴阳八卦河洛九宫十二消息二十四山五行）与太乙、奇门、六壬、纳甲、八字、紫微、堪舆、相术摸骨一术一详述专论
