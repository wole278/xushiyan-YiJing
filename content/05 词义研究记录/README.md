# 05 词义研究记录

> **模块定位**：针对《周易》特定经文词汇、典章名物与特殊字义的专题训诂与辨证考据库。  
> **价值基准评级**：依据 `01 审议体系/01_标准与规范/文档价值基准应用分级体系.md`：
> - 🟢 **1 级文档（核心依赖因子：0.4）**：01、02、03、04、06 篇经 2026-10-21 **用户正式裁定确权晋升为 1 级**，确立为全经核心语义训诂真源与生生动力学总纲，享有最高核心依赖度；
> - 🟢 **2 级文档（核心依赖因子：0.3）**：05 篇（帝乙归妹）为 2 级文档，享有跨卦礼制与结构错位博弈统摄效力。

## 📌 模块规约与文件命名范式

1. **单文档命名与期刊格式标准**：严格执行 **“序号+总结文档”** 规范，后续新撰或重构的词义研究论文**必须严格基于 `01 审议体系/01_标准与规范/学术研究论文撰写格式与期刊级模板规范.md` 中的“模版 A：词义研究期刊级标准论文模版”及八大模块体例撰写**：
   - 格式范例：`两位序号_主题词义研究总结.md`
   - 示例：`01_基于唯物辩证原则的易经匪寇与婚媾原意辨析.md`
2. **研究方法论**：
   - **文字训诂**：追溯甲骨文、金文、简帛本（马王堆帛书、上博简、清华简）原文字形与本义；
   - **名家研注与百年学术论战汇纂**：系统检索古代易经名家专著（王弼《周易注》、李鼎祚《周易集解》辑汉魏诸儒、孔颖达《周易正义》、程颐《伊川易传》、朱熹《周易本义》、永嘉事功学派叶适陈亮、王夫之《周易外传》等）与近现代学术宗师实证考据（顾颉刚、王国维、闻一多、郭沫若、高亨、李镜池、于省吾、张岱年等）；
   - **唯物考辨**：破除汉儒谶纬附会与宋儒道学臆说，还原先秦先民生产劳作、婚俗战守与社会制度原貌；
   - **反哺笺注**：研究结论作为《03 周易笺注》相关卦爻的底层训诂支撑。
3. **分级与依赖机制**：1 级词义成果（因子 0.4）享有全书最高依赖因子与向下公理约束力；2 级词义成果（因子 0.3）对 3 级单卦研判具有直接指导与约束力。
